## 3. Новые возможности (неочевидные)

### 3.1 Партнёрская программа
```
Специалист приглашает коллегу → оба получают 1 месяц бесплатно
```
- Viral growth
- Low cost acquisition

### 3.2 White-label для сообществ
```
Психо-сообщество хочет свою CRM
→ Настраиваемый бренд, они платят $99/мес
```
- B2B revenue
- Network effects

### 3.3 Агрегатор психологов
```
Пользователь ищет психолога → видит профили → записывается
```
- Похоже на Яндекс.Услуги, но для ниши
- Комиссия за запись: 10-15%

### 3.4 Образовательный контент
```
Блог/курс "Как привлекать клиентов психологам"
→ Лид-магнит для специалистов
```
- Бесплатный контент → платные инструменты
- Экспертиза = доверие

### 3.5 Интеграция с телефонией
```
Входящий звонок → автоматически создаётся лид
→ Запись разговора → расшифровка AI
→ Предварительная квалификация
```
- Для тех, у кого много входящих
- Премиум фича

### 3.6 AI-ассистент для специалиста
```
GPT анализирует переписку с клиентом
→ Предлагает следующий шаг
→ Генерирует ответы
```
- Экономит время
- Маленький шаг к Mental Helper Next
